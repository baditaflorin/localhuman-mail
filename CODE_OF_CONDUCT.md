# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Pledge

We pledge to make participation in this project respectful, welcoming, and harassment-free.

## Expected Behavior

- Be kind and constructive.
- Assume good intent, but take responsibility for impact.
- Keep discussions focused on the project and user safety.
- Do not share private mailbox contents, secrets, or personal data in issues or pull requests.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without explicit permission.
- Deliberately submitting code that leaks secrets or mailbox data.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block contributors whose behavior is harmful to the project or community.
